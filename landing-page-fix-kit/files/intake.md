# Intake: evidence before advice

Supply what exists; write **unknown** rather than filling gaps. Redact personal data and secrets. Missing optional material limits scope; it does not automatically fail the page.

## Scope and permissions
- Page URL/version and owner:
- Intended reader and task (approved source, or unknown):
- Audit question and decision to support:
- Read-only scope: inspect supplied/public artifacts only. No form submits, sends, purchases, account creation, installs, deployments, tracking changes, or website/source changes. Local audit documents are the only authorized writes.
- Restricted/logged-in material: request an owner-supplied export; do not guess credentials or bypass access controls.

## Artifact inventory
For each item record ID, filename/URL, capture date, exact section/page, device/viewport if relevant, who supplied it, and limits. Label provenance observed / provided / proposed / unknown.

| Item | What to supply | If absent |
|---|---|---|
| Traffic | Exact ad/post/email/search snippet and intended audience; preserve actual message | External message match Cannot verify; never invent an acquisition promise |
| Landing page | URL plus full copy, desktop and mobile screenshots including footer/form | If inaccessible ask for screenshots/copy; no visual guesses |
| Offer | Approved brief, deliverable, actual PDF/resource and eligibility/price | Page promises can be assessed; fulfillment and contents Cannot verify |
| Proof | Claim text, source data, testimonial permission/context, dates and limitations | Unsupported claim is not proof of falsity; ask for substantiation |
| Action | CTA labels, destination list, field/consent copy, supplied state captures | No live submission; success/error behavior Cannot verify without supplied evidence |
| Journey | Confirmation/delivery captures, actual resource, first-use instructions, next-offer brief, follow-up messages | Map unseen stages unknown; propose separately |
| Measurement | Read-only event dictionary, consent policy, anonymized reports with period/denominator/source | No invented baseline, conversions, gains or implementation claims |

## Decisions to confirm
- Exact resource name, contents, page count/version and price:
- What the primary action promises and when/how delivery occurs:
- Who approves claims, copy, offer changes, and follow-up consent:
- What first useful result means, and whether it is observable or self-reported:
- Known exclusions, technical constraints and accessibility needs:
- Existing next offer and consent-approved follow-up (or unknown):

## Minimum kickoff
A page artifact is enough for a limited audit. State what was inspected and what was not. Missing traffic, analytics or downstream evidence becomes an explicit request, not fabricated findings or an invented offer.
